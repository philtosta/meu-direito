# CHANGELOG — V1.0.0 → V1.0.1 (Meu Direito.IA)

Baseline preservada: `Meu Direito IA V1.dc.html` (V1.0.0) e `Meu Direito IA.dc.html` (V0.1.0). Nenhuma das duas foi alterada nesta rodada.
Versão desta rodada: `Meu Direito IA V1.0.1.dc.html` — **candidata ao congelamento experimental, aguardando auditoria independente**. Base jurídica kb-2026-08-14, verificada em 14/08/2026.

Escopo: apenas os oito achados residuais da auditoria da V1.0.0 e os ajustes necessários para que essas correções funcionem. Nenhuma nova área jurídica, nenhum redesenho.

Todos os testes desta rodada são **verificação interna de desenvolvimento**. A versão não está validada cientificamente.

## Ajustes acessórios necessários

- Cabeçalho, tela "Como funciona" e plano impresso passam a exibir **Versão 1.0.1 — candidata ao congelamento experimental**.
- Título do resultado ganhou variante para o caso de residência não confirmada, para não sugerir caminho onde há requisito pendente.
- Nova prop de configuração `aiEndpoint`, para permitir apontar o endpoint server-side sem editar código.

## O que esta versão não é

Não é uma versão validada, aprovada, auditada de forma independente, livre de erro ou congelada. Não há métrica de acerto jurídico, latência ou taxa de erro nesta rodada, porque nada disso foi medido.
