# Deploy rápido no Vercel

Esta pasta foi preparada para deploy estático.

- `index.html` é uma cópia da versão `Meu Direito V3.dc.html` e será a página inicial.
- Preserve `support.js`, `assets/`, `v2/` e `v3/` na mesma estrutura.
- Não há build nem dependências Node necessárias para esta demonstração.
- No Vercel, importe o repositório e use Framework Preset: **Other**.
- Build Command: deixe vazio.
- Output Directory: deixe vazio/padrão (raiz do repositório).

A aplicação V3 usa armazenamento local do navegador para os fluxos demonstrativos; não requer Supabase para esta demo.
